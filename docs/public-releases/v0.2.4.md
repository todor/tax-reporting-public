## Highlights

- IBKR Appendix 9 paid foreign tax for interest now comes only from `Withholding Tax` detail rows whose description contains `interest`, converted to EUR by the withholding tax row date.
- `Mark-to-Market Performance Summary / Withholding on Interest Received` is no longer used as an Appendix 9 fallback or cross-check, avoiding review noise caused by IBKR summary EUR values differing from row-level FX conversion.
- IBKR trade parsing now accepts `ClosedLot*` as a `ClosedLot` discriminator across parsing, sanity checks, and incomplete-statement validation while preserving the original CSV value in outputs.
