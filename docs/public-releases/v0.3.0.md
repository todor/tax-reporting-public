## Highlights

- Adds position-aware handling for IBKR negative Payment in Lieu of Dividend (PIL) and CFD financing rows, with explicit `NET`, `DEFER`, `IGNORE`, and `REVIEW` decisions in the modified CSV.
- Improves IBKR dividend withholding-tax correction handling, including positive WHT refunds/reversals, prior-year correction output, and informational zero-net foreign-tax reporting.
- Makes CSV number parsing safer across analyzers with per-file decimal-separator detection and analyzer-specific overrides.
- Adds supported IBKR merger/acquisition Corporate Actions handling for SPB-8 quantity reconstruction without treating recognized merger rows as taxable income.

## Tax-impacting changes

- IBKR negative PIL rows are no longer blindly netted. In the default `position-aware` mode, only rows whose final status is `NET` are included in Appendix 5, code 508; `DEFER`, `IGNORE`, and `REVIEW` rows are excluded from current-year netting unless overridden through `Review Status`.
- IBKR CFD financing now uses `--cfd-financing-mode position-aware|always-net|ignore`. Fees rows whose description contains `CFD` are candidates for this flow, Fees `Date` is used as the tax/financing date, and only final `NET` rows affect Appendix 5, code 508.
- IBKR Payment in Lieu rows reported as dividend-like income are included in the Appendix 8 dividend flow by default and no longer require manual review merely because they are PIL.
- IBKR positive dividend WHT rows can be treated either as current-year netting adjustments or as prior-year corrections through `--positive-wht-mode current-year-net|prior-year-correction`. Zero or negative net foreign tax after corrections remains visible, but is informational rather than a warning.
- Recognized IBKR `Merged(Acquisition) WITH` Corporate Actions are treated as non-taxable corporate actions under the project’s current assumption: quantities are applied for reconciliation/SPB-8, but Corporate Actions proceeds/value/P/L do not create Appendix 5/6/8 taxable income.

## IBKR reports and diagnostics

- Modified CSV output now includes clearer review/status columns for negative PIL and CFD financing rows: `Review Status` is preserved as user input, `Auto Status` is the tool decision, `Tax Status` is the final short status, and `Tax Treatment Reason` explains the treatment.
- Main Bulgarian reports now include clearer methodology notes for CFD/PIL handling, previous-year deferred PIL/CFD financing reminders, and concise manual-review instructions that point users to the modified CSV.
- Corporate Actions warnings are consolidated into structured global report diagnostics, while SPB-8 notes remain focused on current-year quantity output.
- Human-readable TXT status headers use cleaner icon labels such as `✅ Статус: УСПЕШЕН` while stdout and machine-readable status values stay unchanged.

## CLI and input handling

- Aggregate tax/reporting options now use generic names such as `--tax-exempt-mode`, `--eu-regulated-exchange`, `--closed-world`, `--negative-pil-mode`, `--positive-wht-mode`, and `--cfd-financing-mode`, with analyzer-specific overrides available through prefixes such as `--ibkr-negative-pil-mode`.
- `--list-aggregate-overrides` lists the supported analyzer-prefixed aggregate overrides without expanding normal help output.
- CSV numeric parsing now resolves a decimal separator per input file (`auto`, `dot`, or `comma`) and avoids unsafe interpretation of ambiguous values such as `1,011`. IBKR grouped quantities such as `-1,100` and `3,015` are parsed as share counts in dot-decimal files.
- SPB-8 input parsing also supports decimal-separator configuration, and diagnostics include more detail about detected formats and ambiguous/mixed evidence.

## P2P documentation

- The README now explains why P2P secondary-market P/L defaults to Appendix 6, code 606 as a conservative receivable/other-income treatment.
- Appendix 5, code 508 is documented as a possible economic interpretation that is not currently supported because it requires transaction-level reconstruction, acquisition-cost linking, partial-sale handling, fees, discounts/premiums, repayments, and cross-year position tracking.

## Documentation and examples

- IBKR documentation was expanded for negative PIL, CFD financing, positive WHT modes, row-date handling, Payment in Lieu dividend treatment, identifier parsing, Corporate Actions, manual-review workflow, and CSV decimal separators.
- E2E expected reports and diagnostics were regenerated for the new status wording, Appendix 5 adjustments, SPB-8 guidance, and informational/warning classifications.
